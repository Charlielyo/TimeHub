# TimeHub - 时间管理工具集

## 项目概述

TimeHub 是一个现代化的时间管理工具集合，采用纯前端技术（Vanilla JS + CSS + HTML）开发，无需后端服务器。项目包含6个核心时间管理工具，帮助用户提高生产力和时间管理效率。

## 功能特性

### 🍅 番茄钟
- 基于番茄工作法的计时器（25分钟专注，5分钟短休息，15分钟长休息）
- 任务管理系统，可关联番茄任务
- 白噪音环境音效（雨声、咖啡馆、森林、篝火）
- 沉浸式全屏模式
- 详细的统计数据和历史记录
- 任务分类和番茄计数

### ⏱️ 秒表
- 精确到毫秒的计时功能
- 分段计时（圈数记录）
- 历史记录和导出功能
- 响应式设计，移动端优化

### ⏰ 多组倒计时
- 创建和管理多个倒计时任务
- 自定义时长和标签
- 分组管理和批量操作
- 定时提醒通知

### 🌐 世界时钟
- 多时区同时显示
- 主要城市时间查询
- 时差计算功能
- 支持夏令时调整

### 📅 截止倒计时
- 重要日期倒计时
- 分类管理（工作、学习、生活）
- 视觉化进度显示
- 自定义提醒设置

### 🧘 呼吸训练
- 引导式呼吸练习（4-7-8呼吸法）
- 视觉化呼吸动画
- 定时器和进度指示
- 放松和专注模式

## 技术栈

- **前端**: Vanilla JavaScript, CSS3, HTML5
- **样式**: CSS变量主题系统，响应式设计
- **存储**: localStorage数据持久化
- **特性**: PWA支持，Service Worker缓存，离线可用
- **兼容性**: 现代浏览器，移动端优先设计

### ⚠️ 已知问题 (Bugs)

#### 高优先级
1. **导出/导入数据按钮无效**
   - 位置：番茄钟页面 → 设置标签页 → 数据管理
   - 现象：点击"导出数据"或"导入数据"按钮无反应
   - 可能原因：事件绑定失败或DOM元素引用错误

2. **主题切换按钮无反应**
   - 位置：所有页面右上角（🌙图标）
   - 现象：点击主题切换按钮无法切换浅色/深色主题
   - 可能原因：common.js中的事件绑定问题

3. **番茄钟文字折叠/截断问题**
   - 位置：番茄钟模式选项卡（专注/短休息/长休息）
   - 现象：在小屏幕上文字显示不完整或被截断
   - 可能原因：响应式布局CSS问题

#### 中优先级
4. **历史记录清理逻辑**
   - 历史记录限制100条，但无时间限制，可能包含很旧的记录

5. **数据备份策略**
   - 缺少自动备份功能，依赖手动导出

#### 低优先级
6. **浏览器兼容性**
   - 某些现代CSS特性在老版本浏览器中可能不支持

## 使用说明

### 快速开始
1. 克隆或下载项目到本地
2. 用现代浏览器打开 `index.html`
3. 直接开始使用各个时间管理工具

### 数据管理
- **导出数据**：番茄钟设置标签页 → 数据管理 → 导出数据
- **导入数据**：选择之前导出的JSON文件恢复数据
- **重置数据**：清除所有本地存储数据
- **备份建议**：定期导出数据到本地文件

### 主题切换
- 点击右上角🌙图标切换浅色/深色主题
- 系统支持自动跟随系统主题设置

### PWA安装
1. 使用Chrome/Edge浏览器访问
2. 点击地址栏右侧的"安装"图标
3. 添加到桌面或应用列表

## 开发说明

### 本地开发
1. 无需构建过程，直接编辑HTML/CSS/JS文件
2. 建议使用现代浏览器开发者工具调试
3. 所有数据存储在浏览器localStorage中

### 代码规范
- JavaScript使用IIFE模式封装模块
- CSS使用BEM-like命名约定
- 使用CSS自定义属性实现主题系统
- 移动端优先的响应式设计

### 测试建议
1. **功能测试**：测试所有工具的计时功能
2. **数据持久化测试**：导出/导入数据功能
3. **响应式测试**：在不同屏幕尺寸下测试布局
4. **主题测试**：切换浅色/深色主题
5. **PWA测试**：离线可用性和安装功能
